# 已确定的广告策略

## 普通模式

- 第一关失败：免费从第一关重来，不展示激励视频入口。
- 第二至第五关失败：自愿完整看一次视频，从当前关卡起点重来；免费重开从第一关开始。
- 重试不保留本关的命中分数和剩余时间，指针、目标区和加速状态随关卡初始化复位。
- 五关通关后永久解锁挑战模式，广告重试不影响这一资格。
- 每次过关结算都是低频插屏候选点，广告关闭后才能操作下一关；失败页不插屏。

## 挑战模式

- 默认未解锁，通关普通五关后永久解锁。
- 未解锁时可自愿完整看一次视频，领取一局挑战体验。
- 资格仅在真正进入挑战时消费；广告完成后尚未进入的资格写入存档保留，不重复要求观看。
- 取消、未完整观看、加载失败不发放资格；广告按钮明确说明“体验一局”。
- 挑战中和挑战结算均不提供广告延续；结束后低频展示插屏。试用玩家再次挑战需要返回模式选择领取新的资格。
- 试用与永久解锁玩家使用相同挑战规则及纪录方式。

## Banner 与全屏广告

- 首页和排行榜共享渠道 Banner，底部居中，尽量避开设备安全区。
- 模式选择、玩法、结算、激励视频和插屏期间隐藏 Banner。
- 新进入会话至少两分钟且累计至少三次过关/挑战结算，才具备插屏资格。
- 插屏共享至少三分钟冷却；激励视频之后至少三分钟不展示插屏；每会话最多两次。
- UI 在全屏广告请求期间禁止重复提交、跳关和重开；晚到的回调不启动已经隐藏的关卡。
- 广告不可用或无填充不阻止免费普通模式、已解锁挑战和正常关卡切换。

## 调试与验收

运行 npm run qa，其中 test-ad-policy.mjs 会转译并执行实际 TypeScript 业务代码，使用模拟 SDK 验证奖励、重试、频控和关闭回调。

浏览器联调需在游戏入口加载之前设置公开运行配置：

    globalThis.__LOCK_MASTER_PLATFORM_CONFIG__ = {
      browserMockAds: true,
      browserMockPlatform: true
    };

生产保持上述两个开关为 false，使用真实广告位；具体平台接入见 platform-setup.md。游戏时间、命中积分和难度曲线未在本次广告改动中调整。
