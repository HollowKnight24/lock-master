# 五关视觉与流程验收标准

本清单用于冻结五关基础体验，不涉及最终时间、目标分数或广告频率。

## 统一视觉标准

- 指针必须横跨轨道凹槽，但两端不得压住轨道金属边框。
- 高亮区域必须完整处于凹槽的内外两条边缘之间。
- 高亮和指针使用同一运动路径；第四关仅高亮按法线向外修正，指针保持在凹槽中心线上。
- 第三关开放端使用平头；第四、第五关闭环接缝不得出现明显断口。
- 黄区、蓝区只改变颜色，不改变宽度、位置或判定范围。

## 每关人工冒烟步骤

1. 使用 `ScenePreview.debugStartLevel` 直达对应关卡。
2. 等待高亮至少刷新三次，观察黄区和蓝区是否始终贴轨。
3. 完成一次命中、一次失误、一次按住加速及释放。
4. 打开暂停，确认倒计时、指针和高亮寿命全部冻结；继续后恢复。
5. 触发成功结算，确认胜利角色素材与庆祝动画；触发失败结算，确认失败素材与动画。
6. 检查重开、下一关和退出首页。
7. 验收结束后把 `debugStartLevel`、`previewPage` 恢复为 0。

## 自动检查

运行 `npm run qa`。其中 `test-five-level-visuals.mjs` 会固定五关节点、第四关凹槽留边、正式首页启动及结算角色动画。自动检查不能替代逐帧目视验收。
