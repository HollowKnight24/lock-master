## 操作

在项目根目录运行：

    npm run art:generate
    npm run art:meta
    npm run art:check
    npm run art:check:cocos

art:generate 只从本地保留母稿机械裁切/缩放，不调用生成服务，也不会重新生成旧 49 张素材。art:meta 只调整 Creator 已生成的元数据，不伪造 UUID；首次导入后运行，然后重新导入。

导出 PNG 的尺寸是游戏使用画布尺寸，不等于母稿原生细节分辨率。背景从 941×1672 母稿适配至 1080×1920；原生尺寸和实际裁切范围以清单为准。
