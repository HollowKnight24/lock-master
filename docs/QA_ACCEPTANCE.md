# 第五阶段：最终验收与交接

第五阶段不改动冻结时间、分数、复活或难度曲线。它将当前版本固定为可试玩候选版本，并把自动验收与真机验收分开记录。

## 自动验收入口

在项目根目录运行：

    npm run qa

该命令依次检查发布准备、页面和音效反馈、平台降级边界、五关完整玩法、轨道视觉边界、编辑器场景、调试预览、正式美术和 TypeScript 编译。若任一项失败，命令会立即以失败状态结束。

## Cocos 编辑器验收

1. 打开 assets/scene.scene，确认启动入口为正常首页。
2. 在 Scene Preview 的 debugStartLevel 分别选择第一至第五关，点击游戏预览；每关完成一次成功命中、一次失误、一次暂停继续和一次重新开始。
3. 恢复 debugStartLevel 为正常首页，保存场景。
4. 在 1080x1920、1080x2160、1080x2400 预览比例下检查顶部信息、底部按钮和首页右上音效按钮。
5. 用构建面板分别生成 Web Mobile、微信小游戏和抖音小游戏产物。

## 真机验收记录

发布负责人需要在每个平台记录机型、系统版本、构建号、首屏加载时间、稳定帧率和内存峰值，并逐项确认：

- 首屏进入首页，无背景音乐，按钮音效、命中音效与结算音效正常。
- 五个关卡的银针、高亮区、轨道和触摸判定一致。
- 刘海、圆角和底部手势区域不遮挡信息或解锁、加速操作。
- 断网、广告不可用、分享取消、排行榜不可用时保持可玩且有明确降级。
- 不含调试入口、测试 AppID、密钥或旧版生产美术。

## 外部依赖

微信和抖音的 AppID、广告位、开放数据域、服务器换取登录态和审核素材由发布方提供后，才能完成对应开发者工具及真机链路。数值平衡在收集试玩数据后单独调整。
